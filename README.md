# DSA-C
A collection of Data Structures and Algorithms (DSA) solutions implemented in C, covering fundamental concepts, problem-solving techniques, and coding practice.

This repository contains my **Data Structures and Algorithms (DSA) solutions in C**.

It includes solutions to problems covering topics such as:

* Arrays
* Strings
* Searching
* Sorting
* Linked Lists
* Recursion
* Stacks & Queues
* Trees
* Graphs
* Hashing
* And more

The goal of this repository is to **practice problem-solving, strengthen DSA concepts, and prepare for coding interviews and placements**.

> 💻 Language: C
> 📚 Focus: DSA & Problem Solving
